A focused catalog for the workspace you already have. No migration, no indexing service, no editor exposed to the network.

Curate projects and knowledge roots through a positive allowlist. Browse folders with file-aware icons and predictable navigation.

Markdown that stays connected

Render GitHub-flavored Markdown and follow relative links without breaking the document flow.

Security by construction

Read-only is a boundary, not a marketing label.

The portal exposes only configured roots and approved file types. Sensitive names, secret stores, hidden paths and escaping symlinks are denied before rendering.

✓No upload, edit, delete, terminal or command endpoint
✓Read-only workspace mount and non-root container
✓Secret-like filenames and key formats denied
✓Strict CSP, response limits and path validation
✓No telemetry or third-party scripts
